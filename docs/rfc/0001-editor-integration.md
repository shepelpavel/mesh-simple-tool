# RFC-0001. Интеграция с редактором: кнопка MST

- Статус: implemented
- Дата: 2026-11-23
- Влияет на: `addons/mesh_simple_tool/plugin.gd`

## Задача

Дать доступ к операциям над UV из панели 3D-вьюпорта, рядом со встроенными действиями над мешом.
Встроенное меню `Mesh` содержит пункт `Unwrap UV2 for Lightmap/AO`; логичное место для новых
пунктов — сразу под ним.

## Решение

Собственная кнопка `MenuButton` с текстом `MST`, вставленная в панель меню 3D-вьюпорта сразу после
`Mesh`. Внутри — четыре пункта: `Scale UV2`, `Unwrap UV`, `Scale UV`, `Merge by distance`.
Кнопка видна только тогда, когда в сцене выделен хотя бы один `MeshInstance3D`.

## Почему так

- Публичного API «добавь пункт во встроенное меню `Mesh`» в Godot 4 нет. `EditorContextMenuPlugin`
  расширяет контекстные меню дерева сцены, а не панель вьюпорта.
- Дописывать пункты прямо в `PopupMenu` встроенного меню технически можно (`add_item` +
  `set_item_index`), но это работает на внутреннем устройстве редактора: меню пересоздаётся,
  порядок пунктов меняется между версиями, а вмешательство необратимо для встроенных действий.
- Своя кнопка рядом — та же доступность, но панель `Mesh` остаётся нетронутой, а точка отказа
  локализована в одном `MenuButton`.

## Реализация

- Поиск панели: `_find_mesh_menu()` рекурсивно обходит `EditorInterface.get_base_control()` и берёт
  `MenuButton`, в popup которого есть пункт с `UV2` (совпадение с `Unwrap UV2 for Lightmap/AO` или
  подстрока `UV2`, поэтому поиск переживает перевод интерфейса). Если такого пункта нет (меню ещё
  не заполнено), допускается первый `MenuButton` с текстом `Mesh`.
- Вставка: `parent.add_child(button)` + `parent.move_child(button, mesh_menu.get_index() + 1)`.
- Показ: `_update_visibility()` вызывается на `selection_changed` и по сторожевому таймеру;
  видимость равна «есть `MeshInstance3D` среди выделенных».
- Сторожевой таймер: `_process` в `EditorPlugin`, интервал `WATCHDOG_INTERVAL = 0.4` с. Нужен потому,
  что панель 3D-вьюпорта пересоздаётся при смене главного экрана редактора, и старая кнопка
  становится невалидной. Проверка живой кнопки дешёвая (`is_instance_valid()` + `is_inside_tree()`),
  повторный обход дерева `base_control` выполняется раз в `MENU_SEARCH_TICKS = 5` тиков (2 с), а
  смена выделения (`selection_changed`) запускает поиск сразу — поэтому в обычном сценарии задержки
  не видно.
- Выбор ноды: `_active_mesh_instance()` возвращает первый `MeshInstance3D` из
  `EditorInterface.get_selection().get_selected_nodes()`.

## Следствия

- Кнопка появляется и исчезает вместе с выделением, не занимая место в панели при работе с другими
  типами нод.
- Действия применяются к одной ноде (первой выделенной), даже если выделено несколько.
- При пересоздании панели кнопка восстанавливается в течение 2 с, а при любом изменении выделения —
  сразу.

## Вне текущего объёма

- Пункты внутри встроенного меню `Mesh` (осознанно отказались, см. «Почему так»).
- Горячие клавиши и пункты в палитре команд редактора.
- Работа с несколькими выделенными нодами за один вызов.
