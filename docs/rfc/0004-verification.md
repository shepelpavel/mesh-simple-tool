# RFC-0004. Проверка: headless-прогоны и ручная приёмка

- Статус: implemented
- Дата: 2026-11-23
- Влияет на: `addons/mesh_simple_tool/tests/`

## Задача

Проверять поведение плагина без открытия редактора и без кликов: математику развёрток, обратимость
масштабирования, сохранение результата в файл сцены и парсинг скриптов.

## Решение

Три headless-скрипта на `SceneTree` плюс проверка синтаксиса через `--check-only`. Все прогоны
работают на сцене `res://tmp/test.tscn` проекта-потребителя: там есть `MeshInstance3D` с
индексированным `ArrayMesh`, у которого присутствуют и UV1, и UV2.

```sh
<godot> --headless --path <project> --script res://addons/mesh_simple_tool/tests/uv_ops_check.gd
<godot> --headless --path <project> --script res://addons/mesh_simple_tool/tests/save_check.gd
<godot> --headless --path <project> --script res://addons/mesh_simple_tool/tests/dialog_signal_order.gd
```

Код возврата 1 при провале — прогоны пригодны для последовательного запуска в одной команде.

## Что проверяет каждый скрипт

`uv_ops_check.gd`:

- масштаб UV2 множителем 0.5 уменьшает размер bbox канала ровно вдвое по обеим осям;
- центр bbox при масштабировании не смещается;
- применение снапшота возвращает координаты UV2 побитово (в пределах 1e-6);
- `Box` и `Cylindrical` дают координаты в 0..1 без `NaN`, `Box` при этом не вырождается в точку
  (суммарная площадь треугольников в UV больше 0.05);
- `Auto` возвращает `ok`, координаты в 0..1, развёртка заполняет квадрат (площадь bbox больше 0.3)
  и исходный UV2 сохраняется;
- число вершин до и после `Auto` печатается в отчёт (на тестовом меше 94 → 94).

`save_check.gd`:

- после применения `Box` сцена упаковывается (`PackedScene.pack`) и сохраняется через
  `ResourceSaver` во временный файл;
- файл перезагружается, первая UV-координата сравнивается с исходной — так проверяется, что правка
  ресурса реально попадает в `.tscn`;
- временный файл удаляется в конце, репозиторий остаётся чистым.

`dialog_signal_order.gd`:

- подтверждает, что кнопки `ConfirmationDialog` испускают `confirmed` и `canceled`.
- **Ограничение:** в headless `Window` не становится видимым (`DisplayServer` dummy), поэтому
  `visibility_changed` не срабатывает и относительный порядок «скрытие → `confirmed`» этим прогоном
  не наблюдается. Этот порядок и обход через `call_deferred` проверяются в живом редакторе
  (см. «Ручная приёмка»).

Проверка синтаксиса:

```sh
for f in plugin.gd uv_ops.gd ui/scale_dialog.gd ui/unwrap_dialog.gd ui/uv_preview.gd; do
  <godot> --headless --path <project> --check-only --script "res://addons/mesh_simple_tool/$f"
done
```

## Ручная приёмка

Выполняется в редакторе, headless-прогонами не покрывается:

1. Выделить `MeshInstance3D` — рядом с `Mesh` появляется `MST`; снять выделение — кнопка исчезает.
2. `Scale UV2`: подвигать ползунок — меш меняется в реальном времени; «Отмена» — возврат;
   повторить и нажать «Применить», затем Ctrl+S и переоткрыть сцену — правка на месте.
3. То же для `Scale UV`.
4. `Unwrap UV`: переключение трёх методов меняет предпросмотр; «Отмена» возвращает исходную UV1.
5. Переключить главный экран редактора на 2D и обратно — кнопка возвращается в панель.

## Следствия

- Регрессии в математике развёрток и в сохранении ловятся за секунды без GUI.
- Отрисовка предпросмотра, модальность окон и порядок сигналов остаются на ручной приёмке.

## Вне текущего объёма

- Автоматические тесты UI (эмуляция кликов, скриншоты редактора).
- Эталонные изображения развёрток.
- Проверка на мешах с blend shapes и с несколькими поверхностями.
