# RFC-0002. Масштабирование UV и UV2

- Статус: implemented
- Дата: 2026-11-23
- Влияет на: `addons/mesh_simple_tool/uv_ops.gd`, `addons/mesh_simple_tool/ui/scale_dialog.gd`

## Задача

Менять масштаб UV-развёртки выбранного меша, видя результат сразу в 3D-вьюпорте, с возможностью
отменить правку и вернуть исходное состояние.

## Решение

Модальное окно (`ConfirmationDialog`) с ползунком и полем точного значения. Диапазон 0.1…100:
ползунок с шагом 0.01, поле ввода с шагом 0.001. Значение применяется к мешу на каждый сигнал
`value_changed`; «Отмена» восстанавливает снапшот, снятый при открытии окна.

Масштабирование — изотропное, вокруг центра ограничивающего прямоугольника канала, общего для всех
поверхностей меша:

```
uv' = center + (uv - center) * scale
```

## Почему так

- Живой предпросмотр требует дешёвой операции. Меш пересобирается из снапшота целиком
  (`snapshot → scaled → apply`), поэтому многократное применение не накапливает ошибку округления
  и не зависит от предыдущих значений ползунка.
- Пивот в центре развёртки выбран как предсказуемый: развёртка остаётся на месте и растёт/сжимается
  симметрично, в отличие от пивота в (0,0), который уводит её из кадра.
- Отдельный снапшот в памяти окна, а не undo-система редактора: по решению владельца операции
  не пишутся в историю отмены.

## Реализация

`uv_ops.gd`:

- `snapshot(mesh)` — массив словарей по поверхностям: `arrays`, `primitive`, `format`, `material`,
  `name`.
- `scaled(snap, channel, factor)` — глубокая копия массивов, пересчёт нужного канала, если он есть.
- `apply(mesh, surfaces)` — `clear_surfaces()` и повторный `add_surface_from_arrays()` с возвратом
  материала и имени поверхности, в конце `emit_changed()`. Флаги формата поверхности переносятся:
  `ARRAY_FLAG_COMPRESS_ATTRIBUTES`, `ARRAY_FLAG_USE_DYNAMIC_UPDATE`, `ARRAY_FLAG_USE_8_BONE_WEIGHTS`,
  `ARRAY_FLAG_USES_EMPTY_VERTEX_ARRAY` — сжатие, режим обновления и скиннинг не теряются.
- `ensure_array_mesh(mesh_instance)` — принимает `ArrayMesh`, конвертирует `PrimitiveMesh`
  через `get_mesh_arrays()` и присваивает ноде новый ресурс.
- `check_supported(mesh)` — возвращает причину отказа (сейчас — blend shapes) или пустую строку;
  диалоги вызывают её до открытия окна.
- `has_channel(snap, channel)` — есть ли у меша данные канала (для подсказки в окне).

`ui/scale_dialog.gd`:

- `open(mesh_instance, channel)` снимает снапшот, сбрасывает значение в 1.0, при наличии —
  показывает предупреждение о том, что меш общий с другими нодами сцены.
- `_on_slider_changed` / `_on_spin_changed` синхронизируют ползунок и поле через
  `set_value_no_signal` и вызывают `_apply(factor)`.
- `_on_confirmed` ставит `_applied = true`, помечает ресурс и сцену изменёнными:
  `EditorInterface.set_object_edited(mesh, true)` и `EditorInterface.mark_scene_as_unsaved()`.
- Откат выполняется в `_settle()`, вызванном через `call_deferred()` из `visibility_changed`.

## Почему откат через `call_deferred`

`AcceptDialog` при нажатии OK сначала скрывает окно (`set_visible(false)`) и только затем испускает
`confirmed`. Обработчик `visibility_changed`, вызывающий откат напрямую, срабатывает раньше
подтверждения и возвращает меш к снапшоту — визуально «Применить» ничего не сохраняет.
Отложенный вызов выполняется после `confirmed`, видит `_applied == true` и откат пропускает.
Та же схема работает для `Esc` и закрытия крестиком.

## Следствия

- Правка не попадает в историю отмены редактора; откат возможен только пока окно открыто.
- Изменение не сохраняется в файл сцены само по себе: сцена помечается изменённой, сохранение —
  за пользователем (Ctrl+S).
- Меши с blend shapes не поддерживаются: `check_supported()` отказывает, потому что пересборка
  поверхностей не переносит blend-данные.
- Для `PrimitiveMesh` исходный ресурс-примитив теряется: нода получает `ArrayMesh`.
- Общий меш (один ресурс на несколько нод) меняется для всех нод сразу; окно предупреждает.

## Вне текущего объёма

- Undo/Redo через `EditorUndoRedoManager`.
- Выбор пивота (центр, (0.5, 0.5), (0, 0)) и раздельный масштаб по осям.
- Масштабирование всех выделенных нод.
- Работа с мешами, у которых есть blend shapes: они не сохраняются при пересборке поверхностей.
