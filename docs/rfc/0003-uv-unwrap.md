# RFC-0003. Автоматическая развёртка UV1

- Статус: implemented
- Дата: 2026-11-23
- Влияет на: `addons/mesh_simple_tool/uv_ops.gd`, `addons/mesh_simple_tool/ui/unwrap_dialog.gd`,
  `addons/mesh_simple_tool/ui/uv_preview.gd`

## Задача

Разворачивать UV1 выбранного меша автоматически, с предпросмотром результата и выбором метода из
нескольких вариантов разной сложности.

## Решение

Окно с селектором из трёх методов, предпросмотром UV и кнопками «Применить»/«Отмена».
Переключение метода сразу перестраивает UV1 в меше и обновляет предпросмотр; «Отмена» возвращает
снапшот.

| Метод | Реализация |
|---|---|
| `Box / planar` | `box_unwrapped()`: осевая проекция вершины по доминирующей оси нормали |
| `Auto (angle-based)` | `lightmap_unwrapped()`: `ArrayMesh.lightmap_unwrap()` (xatlas), результат переносится в UV1 |
| `Cylindrical (Y)` | `cylindrical_unwrapped()`: `u = atan2(-z, x)/2π + 0.5`, `v` по диапазону Y |

## Почему так

- Встроенной развёртки UV1 в Godot 4 нет. Единственный готовый алгоритм — `lightmap_unwrap`,
  который пишет в UV2; он и стал методом `Auto`.
- `Box` и `Cylindrical` — собственная реализация без внешних зависимостей: предсказуемый результат
  на архитектурных мешах и трубах, работает headless, не требует индексов.
- Все три метода приводятся к одному виду: нормализация в 0.02…0.98 с сохранением пропорций по
  большей стороне. Без неё `lightmap_unwrap` отдаёт координаты в собственных единицах (зависят от
  `texel_size`), а осевые проекции — в метрах сцены.

## Реализация

`uv_ops.gd`:

- `box_unwrapped(snap, padding)` — для каждой вершины берётся нормаль (при отсутствии — `Vector3.UP`),
  выбирается ось по максимальной компоненте, проекция с учётом знака нормали, затем `_normalize()`.
- `cylindrical_unwrapped(snap, padding)` — ось Y, угол через `atan2`, `v` из диапазона Y поверхности,
  затем `_normalize()`.
- `lightmap_unwrapped(snap, padding)` — собирает временный `ArrayMesh` из снапшота, при отсутствии
  индексов генерирует их (`0..N-1`), вызывает `lightmap_unwrap(Transform3D.IDENTITY, 1.0)`,
  забирает полученный UV2 в UV1. Если массивы вершин результата совпадают с исходными, исходный UV2
  восстанавливается; иначе он остаётся равным новой развёртке. Ошибка возвращается словарём
  `{"ok": false, "error": ...}`, окно показывает её и остаётся на `Box`.
- `_normalize(surfaces, padding)` — общий bbox по всем поверхностям, равномерный коэффициент,
  центрирование.

`ui/unwrap_dialog.gd` — селектор, предпросмотр, обработка ошибки `Auto`, откат по `canceled`/
закрытию через `call_deferred` (та же причина, что в RFC-0002).

`ui/uv_preview.gd` — `Control` с `_draw()`: фон, сетка 0..1 и четверти, рамка, рёбра треугольников
по индексам (или по тройкам вершин), подпись с числом треугольников и количеством вершин вне 0..1.
Отрисовка ограничена `MAX_DRAW_TRIS = 20000` треугольниками, чтобы окно не вставало на больших мешах;
в подписи тогда пишется «N of M tris (limited)».

## Следствия

- `Box` не упаковывает острова: грани, спроецированные на одну ось, накладываются друг на друга.
  Это ожидаемое поведение «простой» проекции, а не ошибка.
- `Auto` зависит от наличия xatlas в сборке движка и может изменить число вершин; исходный UV2
  в этом случае не восстановить.
- `Cylindrical` даёт шов по направлению `-X`; вершины на шве получают крайние значения `u`.
- Нормализация общая на весь меш: у многоматериальных мешей острова разных поверхностей могут
  перекрываться.
- Предпросмотр читает UV1 с живого меша, поэтому всегда показывает текущее состояние, включая
  промежуточные результаты переключения методов.

## Вне текущего объёма

- Упаковка островов в атлас (bin packing) и контроль перекрытий.
- Seam-aware развёртка UV1 собственными силами (разрезание по рёбрам, чарты).
- Настройка `texel_size`, отступа и разрешения лайтмапа из окна.
- Развёртка нескольких выделенных мешей одним вызовом.
- Отдельный предпросмотр в 3D (встроенный `UV Channel Debug` недоступен из плагина: его класса нет
  в ClassDB).
