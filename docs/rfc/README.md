# Каталог RFC

Решения по устройству плагина. Один документ — один слой. Статус `implemented` значит, что описанное
поведение есть в коде; планы и нереализованное живут в RFC со статусом `draft`.

| RFC | Тема | Статус |
|---|---|---|
| [RFC-0001](0001-editor-integration.md) | Интеграция с редактором: кнопка `MST`, вставка в панель, видимость по выделению | implemented |
| [RFC-0002](0002-uv-scale.md) | Масштабирование UV/UV2: окно, живой предпросмотр, откат, пометка сцены | implemented |
| [RFC-0003](0003-uv-unwrap.md) | Автоматическая развёртка UV1: методы, нормализация, предпросмотр, сохранение UV2 | implemented |
| [RFC-0004](0004-verification.md) | Проверка: headless-прогоны, синтаксис, ручная приёмка | implemented |
| [RFC-0005](0005-merge-by-distance.md) | Слияние вершин ближе заданной дистанции: сетка, union-find, живой счётчик | implemented |

## Состояние сейчас

Версия плагина 0.2.0 (`addons/mesh_simple_tool/plugin.cfg`). Реализованы все пять слоёв: интеграция
с редактором, масштабирование UV/UV2, развёртка UV1, проверка и слияние вершин. Проверены
headless-прогонами. Известные ограничения перечислены в `README.md` и в разделах «Вне текущего
объёма» каждого RFC.

## Правила ведения

- Один RFC — одно решение. Новый слой — новый номер, а не раздел в чужом файле.
- Изменение принятого решения — правка раздела с пометкой даты либо новый RFC со ссылкой на предыдущий.
- Нереализованное помечается `draft` и не описывается как факт; в шапке — дата и автор.
- Ссылки в индексе должны существовать: проверка
  `grep -oE '\]\([0-9]{4}-[^)]+\)' docs/rfc/README.md` и сверка с содержимым каталога.
