# mesh-simple-tool

Плагин редактора Godot: быстрые операции с UV-развёртками прямо из 3D-вьюпорта.

Добавляет в панель 3D-вьюпорта кнопку **MST** сразу после встроенного меню `Mesh`. Кнопка видна только
когда в сцене выделена нода `MeshInstance3D`. В меню три пункта:

| Пункт | Что делает |
|---|---|
| `Scale UV2` | Масштабирование канала UV2 выбранного меша с живым предпросмотром |
| `Unwrap UV` | Автоматическая развёртка UV1 с окном предпросмотра и выбором метода |
| `Scale UV` | Масштабирование канала UV1 |
| `Merge by distance` | Слияние вершин, находящихся ближе заданной дистанции |

## Требования

- Godot 4.x (разработано и проверено на 4.7.1).
- Проект, в который устанавливается плагин, должен открываться в редакторе, а не запускаться из CLI.

## Установка

1. Скопировать каталог `addons/mesh_simple_tool/` в `addons/` проекта.
2. `Project → Project Settings → Plugins` → включить `Mesh Simple Tool`.
3. Открыть 3D-сцену, выделить `MeshInstance3D` — рядом с `Mesh` появится `MST`.

Плагин на GDScript, компиляции не требует. Файлы `.uid` рядом со скриптами коммитятся вместе с ними:
без них редактор пересоздаёт идентификаторы из кэша и пишет предупреждения `Missing .uid file`.

## Использование

### Scale UV / Scale UV2

Открывается окно с ползунком (0.1…100, шаг 0.01) и полем точного ввода (0.1…100, шаг 0.001).
Значение применяется к мешу сразу при движении ползунка.

- Пивот масштабирования — центр ограничивающего прямоугольника канала UV/UV2.
- «Применить» фиксирует результат и помечает сцену изменённой (Ctrl+S сохранит).
- «Отмена», `Esc` или закрытие окна крестиком возвращают состояние на момент открытия.
- Если меш используется несколькими нодами сцены, в окне появляется предупреждение.

### Unwrap UV

Открывается окно с предпросмотром UV1 (сетка 0..1, рёбра треугольников, счётчик вершин вне диапазона),
селектором метода и кнопками «Применить»/«Отмена».

| Метод | Как работает |
|---|---|
| `Box / planar` | Осевая проекция каждой вершины по доминирующей оси нормали |
| `Auto (angle-based)` | `ArrayMesh.lightmap_unwrap` (xatlas), результат переносится в UV1 |
| `Cylindrical (Y)` | Цилиндрическая проекция вокруг оси Y, шов по `-X` |

Развёртка нормализуется в диапазон 0.02…0.98 с сохранением пропорций. Переключение метода сразу
перестраивает UV1 в меше; «Отмена» возвращает исходное состояние.

### Merge by distance

Окно с ползунком дистанции; максимум подбирается по диагонали меша — 0.5 % диагонали в пределах
0.0001…100, минимум 0.
Под ползунком показывается, сколько вершин будет слито и сколько треугольников удалится. На мешах
до 30 000 вершин счётчик пересчитывается на каждое изменение (не чаще раза в 100 мс), на более
крупных — по отпусканию ползунка или смене галочки, чтобы редактор не замирал.

Считается по геометрии: вершины ближе `distance` объединяются в одну (позиция берётся у вершины
с меньшим индексом), UV на слияние не влияет — после него UV, тангенты и цвета берутся у представителя.
Треугольники, потерявшие площадь, удаляются, неиспользуемые вершины вычищаются. «Отмена» ничего не меняет.

Галочка **«Сохранять плоское затенение (учитывать нормали)»** (включена по умолчанию) не даёт сливать
вершины с разными нормалями — hard edges остаются на месте, но сливается меньше вершин. Без неё
сливаются все вершины в пределах дистанции, а нормали группы усредняются: меш становится гладким.
Счётчик показывает оба числа сразу — для текущего режима и для противоположного.

В Godot нет split normals: плоское затенение держится на раздельных вершинах с одинаковой позицией.
Поэтому слияние вершин с разными нормалями визуально сглаживает меш — это ограничение движка, а не
плагина. Если после слияния планируется `Unwrap UV`, галочку стоит включить: `Box`-развёртка выбирает
ось по нормали.

При `distance = 0` сливаются только точно совпадающие позиции — так же ведёт себя Blender.

## Ограничения

- Операции не пишутся в историю отмены редактора (по решению владельца): Ctrl+Z правку не откатит,
  откат — только через «Отмена» в открытом окне.
- `Box / planar` не упаковывает острова: грани, спроецированные на одну ось, накладываются друг на друга.
- `Auto` — единственный метод с разбиением на чарты; при изменении топологии xatlas'ом исходный UV2
  восстановить нельзя и он остаётся равен новой развёртке.
- Нормализация общая на весь меш: у многоматериальных мешей развёртки поверхностей могут перекрываться.
- `Scale` применяется к первому выделенному `MeshInstance3D`, остальные выделенные ноды не затрагиваются.
- `PrimitiveMesh` (`BoxMesh`, `CylinderMesh` и т. п.) конвертируется в `ArrayMesh` при первом применении:
  параметры примитива в инспекторе после этого недоступны.
- Предпросмотр UV в окне развёртки ограничен 20 000 треугольниками: на больших мешах рисуется
  часть, в подписи указано «N of M tris (limited)».
- Меши с blend shapes не поддерживаются: операция отменяется с предупреждением в консоли редактора,
  потому что пересборка поверхностей удалила бы blend-данные.
- `Merge by distance` сливает вершины только внутри одной поверхности; между поверхностями одного
  меша слияния нет.

## Структура репозитория

```
addons/mesh_simple_tool/
  plugin.cfg            манифест плагина
  plugin.gd             EditorPlugin: кнопка MST, меню, показ по выделению
  uv_ops.gd             операции над мешами: снапшот, масштаб, развёртки
  ui/scale_dialog.gd    окно масштабирования UV/UV2
  ui/unwrap_dialog.gd   окно развёртки UV1
  ui/uv_preview.gd      предпросмотр UV (Control._draw)
  ui/merge_dialog.gd    окно слияния вершин по дистанции
  tests/                headless-проверки
docs/rfc/               решения по устройству плагина
AGENTS.md               правила работы в репозитории
```

## Проверка

Headless-прогон без открытия редактора:

```sh
<godot> --headless --path <project> --script res://addons/mesh_simple_tool/tests/uv_ops_check.gd
<godot> --headless --path <project> --script res://addons/mesh_simple_tool/tests/save_check.gd
<godot> --headless --path <project> --script res://addons/mesh_simple_tool/tests/merge_check.gd
```

Проверка синтаксиса отдельного скрипта:

```sh
<godot> --headless --path <project> --check-only --script res://addons/mesh_simple_tool/plugin.gd
```

Все прогоны возвращают код 1 при провале. Подробности — в `docs/rfc/0004-verification.md`.
Если в проекте есть автолоады, которые держат процесс (например, MCP-мост редактора), прогон
завершится по таймауту уже после печати результата — судить по строке `ALL CHECKS PASSED` либо
гонять тесты в чистом проекте-песочнице.
